## Критерии приёмки

- [ ] **Офлайн-Стратег:** получает найденные интересы (каталог из поиска Meta/фейка, который ему уже передаёт Planning) и строит план из ≥ 2 групп, когда бюджет позволяет (широкая + интересы; ретаргетинг — если аудитория достаточна). `tests/e2e/test_demo_cycle.py::test_offline_demo_plan_has_at_least_two_groups…` — без `xfail`, зелёный; в офлайн-демо после «+7 дней» есть перераспределение бюджета с объяснением (тест). Перегенерировать `docs/demo-transcript.md` через `./scripts/demo-transcript.sh` — в нём видно перераспределение.
- [ ] **Один модуль ключей настроек** `config/runtime.py`: имена ключей (`level`, `halted`, `optimizer_rules`, `alert_thresholds`, `report_time`, `report_tz`, `install_id`, `overspend` и прочие, что найдёшь) и их значения по умолчанию; все модули импортируют отсюда, повторных литералов ключей и дефолтов нет (тест: grep-проверка, что строковые литералы этих ключей встречаются только в `config/runtime.py` и тестах). Дефолт `min_hours_before_decision=72` и остальные правила оптимизатора берутся из `policy.OptimizerRules` — один источник; тест-мутация: изменение 72 в этом источнике краснит e2e-тест «до 72 ч решений нет».
- [ ] **Темп без шума:** пересчёт темпа не делает изменений бюджета меньше порога (константа, например < 1% бюджета группы или < 1 минимальной единицы × 100), и такие «копеечные» правки не попадают в итог перемотки; текст «бюджет переносится на сильные группы» выводится, только если сильные группы есть, иначе — честная формулировка («сильных групп пока нет — бюджет не перераспределялся»).
- [ ] `OptimizationResult.lines` и все тексты, которые ops отдаёт наружу, — без служебного тега `[ta:…]`.
- [ ] **Стоп-кран после вызова:** повышение бюджета группы (`apply_decisions`) и `spend_cap` (`month_rollover`), пришедшее во время стоп-крана, откатывается после вызова, если флаг поднялся (как `enable_object` для включения). Тест.
- [ ] `ensure_engagement_audience` не усыновляет аудиторию с нашим тегом, созданную раньше записи попытки (та же проверка времени создания, что у шагов запуска). Тест.
- [ ] `services/admin/companies.py` создаёт подтверждения через `Executor.create_approval` (с параметром для намерения), а не собирает payload сам.
- [ ] `httpx2` (используется тестами напрямую) объявлен в dev-зависимостях `pyproject.toml` — без установки новых пакетов (он уже стоит транзитивно; `uv lock` только фиксирует).
