## Что должно заработать

Доказательство готовности по критериям 1–3 брифа — через главный шов: всё приложение, фейковый Telegram, скриптовая модель, фейковый Graph API, симулированные часы. Плюс стенограмма демо-прогона, которую пользователь может прочитать, не открывая Telegram.

## Из брифа, дословно

> «В демо-режиме проходит весь цикл без Meta: добавил компанию → паспорт → медиаплан → „Запустить“ → кампания запущена → перемотка на 7 дней → оптимизатор перераспределил бюджет по правилам и прислал отчёт с объяснениями. Тот же цикл прогоняет сквозной автотест с заглушками Telegram и модели.»
> «Автотесты закрывают всё, что касается денег: лимит не превышается ни при каком ответе модели (включая заведомо вредный), пересчёт валют, двойное нажатие даёт одну кампанию, восстановление после сбоя посреди запуска, чужой Telegram ID получает отказ, кампании не из системы не затрагиваются, стоп-кран ставит всё на паузу и ничего не включается само.»
> «Работа с Meta проверена на фейковом API, который повторяет реальные ответы и ошибки: истёкший токен, нет прав, лимит запросов, отклонённое объявление.»
