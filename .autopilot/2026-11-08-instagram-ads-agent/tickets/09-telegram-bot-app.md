## Что должно заработать

Настоящий бот на aiogram с long polling, который отвечает только людям из белого списка, по-русски, кнопками и обычным текстом, и связывает все сервисы. `python -m target_ai` поднимает приложение: настройки → база → часы и шлюзы по уровню (демо: фейк + симулятор; тест: реальная Meta с `validate_only`; боевой: реальная Meta) → восстановление прерванных запусков → планировщик → polling.

## Из брифа, дословно

> «Я вижу всё в Telegram и подтверждаю ключевые решения кнопками.»
> «Бот отвечает только Telegram ID из списка в настройках, остальным — отказ.»
> «Интерфейс — только Telegram-бот на long polling (без домена и HTTPS). Понимает обычный текст, для частых действий — кнопки. Язык — русский.»
> «Кнопка подтверждения срабатывает один раз … Двойное нажатие, повтор от Telegram или сбой сети не создают вторую кампанию.»

## Критерии приёмки

- [ ] Middleware доступа первым: чужой ID на любое сообщение/колбэк → «Доступ закрыт.» и ничего больше, запись в журнал не чаще раза в час на ID; тест через фейковую сессию
- [ ] Меню и команды из §8; демо-кнопки «⏩ +1 день / +7 дней» только в демо; текущий уровень виден в `/start` и в меню
- [ ] Колбэки `ap:<id>:<choice>` → атомарное потребление подтверждения → действие; повторное нажатие/повтор апдейта → «Уже выполнено»/«Устарело»; повтор `update_id` игнорируется (`processed_updates`)
- [ ] Свободный текст → разбор намерений → сервис; денежные намерения — только через подтверждение; непонятное → «Не понял. Вот что я умею: …» + меню
- [ ] Фото/видео принимаются и передаются сервису креативов; длинные тексты режутся ≤ 4096, HTML экранируется
- [ ] `App.create(settings, overrides)` собирает всё; `overrides` подменяют `llm`, `meta_transport`, `clock`, `bot_session`, `notifier` (шов №1); без ключа Claude — `OfflineLLM`; без токена бота `python -m target_ai` пишет по-русски, что вписать в `.env`, и выходит с кодом ≠ 0
- [ ] При старте: `Executor.recover_incomplete()` и уведомление о прерванных запусках; планировщик запущен; `delete_webhook` перед polling; корректная остановка по Ctrl+C
- [ ] `tests/support/fake_telegram.py`: сессия aiogram, которая перехватывает исходящие запросы (сообщения, клавиатуры, правки) и даёт тестам подать апдейты от любого ID
- [ ] Тест: от `/start` до сводки анкеты в демо через фейковую сессию
- [ ] Дописать в `interfaces.md` сигнатуры `App`, `Notifier`, фейковой сессии
