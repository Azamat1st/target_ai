# Интерфейсы

Этот файл читает каждый исполнитель **до того, как писать код**. Сверху — правила проекта и границы, решённые в спецификации (копия `spec.md` → «Границы и швы»). Снизу — то, что построили завершённые таски: их публичные сигнатуры дописываются после каждого таска.

## Правила проекта

- **Стек.** Python 3.12 (`.python-version`), менеджер — `uv` (`pyproject.toml` + `uv.lock`). Пакет — `src/target_ai/`, тесты — `tests/`. Зависимости (ставит **только таск 01**, одной командой, все сразу): `aiogram>=3.31,<4`, `anthropic>=2.6,<3`, `httpx>=0.28`, `pydantic>=2.12,<2.14` (aiogram 3.31 требует <2.14 — обнаружено таском 01), `pydantic-settings>=2.16`, `tzdata`; dev: `pytest>=9`, `pytest-asyncio`, `pytest-cov`. Любой следующий таск, которому не хватает пакета, **не ставит его**, а возвращает `BLOCKED` с названием пакета.
- **Команды.** `uv sync` — установка; `uv run pytest -q` — все тесты; `uv run pytest tests/<путь> -q` — часть; `./start.sh` — запуск бота; `uv run python -m target_ai` — то же без проверок.
- **Сеть в тестах запрещена.** Meta — только через `FakeGraphAPI.transport`; Claude — `ScriptedLLM`/`OfflineLLM`; Telegram — фейковая сессия бота. Ни один тест не требует `.env`.
- **Деньги** — только `money.Money` (целые минимальные единицы + валюта). `float` для денег запрещён; ввод — `Decimal`.
- **Время** — только через `clock.Clock` (`now()` — aware datetime в UTC; перевод в часовой пояс аккаунта — `zoneinfo`). Прямой `datetime.now()` вне модуля `clock` запрещён.
- **Изменения в Meta** — только модуль `executor`. Модули `agents`, `services`, `bot` не вызывают изменяющие методы `MetaGateway` (проверяется тестом на импорты/вызовы в таске 05).
- **Агенты** не импортируют `storage`, `meta`, `executor`.
- **Секреты** — только из `config.Settings`; в лог и в сообщения не попадают. Логгер — `logging`, никакого `print` в коде приложения.
- **Стиль** (правила пользователя): неизменяемые структуры (`@dataclass(frozen=True)`, pydantic `frozen` где уместно), обновление — новой копией; файлы 200–400 строк, максимум 800; функции < 50 строк; вложенность ≤ 4; константы вместо «магических чисел»; ошибки обрабатываются явно, ничего не глотается молча; пользовательские тексты — на русском; идентификаторы — на английском.
- **Тесты.** pytest, структура Arrange-Act-Assert, имена описывают поведение. Сначала тест (красный), затем код. Покрытие нового кода ≥ 80% (`uv run pytest --cov=target_ai`).
- **Не трогать:** `.autopilot/` (кроме случаев, когда таск прямо говорит), `.env`.
- **Справочники.** Meta — `.autopilot/2026-11-08-instagram-ads-agent--wip/research-meta.md` (по номерам разделов, указанным в спеке §6). Claude SDK — скилл claude-api: `/private/tmp/claude-501/bundled-skills/2.1.318/ce473a25ae335659c3fa55f2c2835583/claude-api/python/claude-api/README.md` и `tool-use.md` (structured outputs через `client.messages.parse(..., output_format=Model)`, server tools `web_search_20260209`/`web_fetch_20260209`, vision base64, `thinking={"type":"adaptive"}`, `output_config={"effort": ...}`, без `temperature`/`top_p`, без prefill, без forced `tool_choice`). Если папка скилла недоступна — опираться на формулировки спеки §5.
- **Спецификация** — `.autopilot/2026-11-08-instagram-ads-agent--wip/spec.md`; словарь терминов — там же, раздел «Словарь».

## Что построено

_(дописывается после каждого таска: публичные сигнатуры, которые реально существуют в коде, и всё, что отличается от плана выше)_

### Таск 01 — каркас (построено)

**Отличие от плана:** `pydantic>=2.12,<2.14` вместо `>=2.14` — `aiogram 3.31` требует `pydantic<2.14` (установлено 2.13.5). `pytest` настроен в `pyproject.toml` (`asyncio_mode=auto`, `pythonpath=src`).

- `config`: `Settings` (pydantic-settings, frozen; секреты — `SecretStr | None`: `telegram_bot_token`, `anthropic_api_key`, `meta_access_token`, `meta_app_secret`; `.get_secret_value()`), поля: `telegram_allowed_ids: tuple[int,...]`, `model_strong`, `model_cheap`, `meta_app_id: str|None`, `meta_api_version`, `database_path: Path`, `report_tz`, `log_level`. `load_settings(env_file=".env") -> Settings` (окружение процесса важнее файла; пустые значения = не заданы).
- `logging_setup`: `setup_logging(level="INFO")` (идемпотентна; маскирует секреты на обработчике; `httpx`/`httpcore` ≥ WARNING), `mask_secrets(text) -> str`.
- `money`: `Money(amount_minor:int, currency:str)` frozen; `+ - < <= > >=` (разные валюты → `CurrencyMismatch`), `.to_major() -> Decimal`; `from_major(Decimal, currency)`; `offset(currency)->int`; `format_ru(Money)->str`; `parse_amount_ru(text)->(Decimal, str|None)` (ValueError, если числа нет). Исключения (все наследуют `MoneyError(ValueError)`): `UnknownCurrency`, `FractionalAmountError`, `CurrencyMismatch`. `float` в `Money`/`from_major` → `TypeError`.
- `clock`: `Clock` (протокол `now()`), `RealClock()`, `SimClock(store: OffsetStore, base: Clock|None=None)` с `.advance(timedelta)` (назад — ValueError), `OffsetStore` (`get_offset()/set_offset(timedelta)`), `to_account_time(moment, tz_name) -> datetime`.
- `storage`: `Database(path | ":memory:")` — синхронный (звать через `asyncio.to_thread`); `.transaction()` (контекст, вложенные = savepoint), `.close()`. Ошибки: `StorageError`, `NotFound`, `AlreadyLaunched(plan_id)`. Модели (frozen, kw_only, `id: int = 0` → после `create` приходит копия с id; обновление — `dataclasses.replace` + `update`): `Company, Fact, Passport, MediaAsset, Plan, Launch, LaunchStep, MetaObject, Approval, DailyStat, HistoryEntry, AuditEntry, Job, DialogState`. Время в моделях — только aware datetime (naive → ValueError); `created_at` ставит вызывающий.
  - Обычные репозитории `get(id) / list(order_by="id"|"-col", limit=None, **eq_filters) / create(model) / update(model)`: `db.companies`, `facts`, `media`, `launch_steps`, `history`, `passports` (+`latest(company_id)`), `plans` (+`latest(company_id)`), `launches` (+`get_by_plan(plan_id)`; повторный `create` для плана → `AlreadyLaunched`), `objects` (+`get_by_meta_id`), `audit` (без `update`), `stats` (+`upsert(DailyStat)`, `list_range(company_id, start_iso, end_iso)`), `jobs` (+`schedule(kind, due_at, company_id=0)`, `due(now)`).
  - `db.approvals`: `create(kind=, now=, company_id=None, payload=None, ttl=24h) -> Approval` (id — случайный hex-токен `str`), `get(id)`, `consume(id, now) -> Approval | None` (None = не потреблено: нет/использовано/просрочено/отменено), `cancel(id) -> bool`.
  - `db.settings`, `db.fake_meta`: `get(key, default=None) / set(key, json_value) / list() -> dict / delete(key)`.
  - `db.alerts`, `db.updates`: `mark(key, now) -> bool` (True только при первом), `seen(key)`.
  - `db.dialogs`: `get(chat_id)`, `save(DialogState)`, `delete(chat_id)`. `db.sim`: `get_offset()/set_offset()` (реализует `OffsetStore`; передавать в `SimClock(db.sim)`).
  - Деньги в моделях: `Company.monthly_limit/target_cpa`, `MetaObject.daily_budget`, `DailyStat.spend` — `Money | None` (две колонки `<имя>_minor`/`_currency`). Миграции — `storage/migrations/NNNN_*.sql` (новые таски добавляют следующий номер).
- **Правило транзакций (ревью таска 01):** `transaction()` держит блокировку на весь блок, поэтому транзакция целиком выполняется внутри одного вызова `asyncio.to_thread(...)`: синхронная функция, внутри которой `with db.transaction(): …`. Никаких `await` внутри `with db.transaction()` — зависнет.
- `logging_setup.mask_secrets(text)` выставлена наружу намеренно: ею маскируют тексты ошибок перед отправкой пользователю.
- Запуск: `./start.sh`; `python -m target_ai` пока заглушка (лог + код 0). Тестовые фикстуры: `tests/conftest.py` → `db` (файловая база в tmp), `now`.

### Таск 03 — клиент Meta, фейковый Graph API, симулятор (построено)

**Отличия от плана:** клиент и шлюз **асинхронные** (`await`); сон ретраев — через инжектируемый `sleeper` (по умолчанию `asyncio.sleep`), время — `Clock`. `validate_only=True` → `create_*` возвращает `None` (объект не создан), иначе `str` id. Объекты — dict (JSON как у Graph API), деньги на проводе — строка минимальных единиц.

- `target_ai.meta`: `MetaClient(token, version="v27.0", transport=None, validate_only=False, app_secret=None, clock=None, *, app_id=None, sleeper=None, model_name="")`, `await client.aclose()`. Тот же набор методов описан протоколом `MetaGateway`:
  - чтение: `list_ad_accounts()->list[AdAccount]`, `get_ad_account(account_id)->AdAccount`, `get_minimum_budgets(account_id)->dict["imp"|"high_freq"|"low_freq", Money]`, `list_pages()->list[dict]` (без токенов), `get_page_instagram(page_id)->str|None`, `search_interests(query, limit=25)->list[dict]`, `estimate_audience(account_id, targeting_spec, optimization_goal, promoted_object=None)->(low, high)|None` (`-1` → None; запасной `/reachestimate`), `get_insights(object_id, *, level, since: date, until: date, fields=None)->list[dict]` (строки как в `/insights`, `time_increment=1`), `get_ad_status(ad_id)->dict`, `find_by_name_tag(parent_id, edge, tag)->list[dict]` (edge: campaigns|adsets|ads|adcreatives; отбор по тегу в имени), `get_ig_profile(ig_user_id)`, `get_ig_media(ig_user_id, limit=50)`, `get_ig_media_insights(media_id)->dict[str,int]`, `business_discovery(ig_user_id, username)->dict|None`, `debug_token()->TokenInfo` (`is_valid, expires_at, expiry_known, scopes, data_access_expires_at`; без app_id/секрета — через `/me`, `expiry_known=False`), `get_engagement_audience_size(audience_id)->int|None`.
  - изменение: `create_campaign|create_adset|create_creative|create_ad(account_id, params: Mapping, *, idempotency_key=None)->str|None`, `create_audience(account_id, params)->str`, `upload_image(account_id, data: bytes, filename)->image_hash`, `upload_video(...)->video_id`, `set_status(object_id, status)`, `set_daily_budget(object_id, budget: Money)`, `set_spend_cap(campaign_id, cap: Money)` (валюта сверяется с аккаунтом самого объекта: клиент узнаёт его `GET /{id}?fields=account_id` и кэширует), `delete(object_id)`. Деньги в `params` (`daily_budget`, `lifetime_budget`, `spend_cap`, `bid_amount`) — только `Money` в валюте аккаунта (иначе `TypeError` / `MetaError(kind="currency_mismatch")` до запроса).
  - `AdAccount(id, name, currency, timezone_name, account_status, disable_reason, funding_source, min_campaign_group_spend_cap: Money|None)`, `.is_active`.
  - `MetaError(kind, user_message_ru, *, code, subcode, retry_after, fbtrace_id, blame_fields: tuple[str,...], http_status, is_transient, outcome_unknown)`. `kind`: `token_expired, token_invalid, permission, rate_limit, invalid_parameter, api_version, ig_access, audience_terms, spend_cap_too_low, budget_too_low, ad_disapproved, eu_dsa, transient, network, currency_mismatch, validate_only_unsupported, unknown` (константы в `target_ai.meta.errors`).
