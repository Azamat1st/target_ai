## Что должно заработать

Человек без технического опыта по README получает все ключи и доступы, запускает бота на Mac одной командой, проходит демо, переходит в тест и в боевой, и разворачивает на VPS через Docker. На сервер ничего не разворачивается — только файлы и инструкция.

> «Запуск на моём Mac одной командой, плюс Docker и инструкция для VPS. На сервер сам не разворачивай.»

- [ ] `Dockerfile` (python:3.12-slim + uv, непривилегированный пользователь, `uv sync --frozen --no-dev`), `docker-compose.yml` (`env_file: .env`, том `./data:/app/data`, `restart: unless-stopped`), `.dockerignore` (без `.env`, `.venv`, `data/`, `.autopilot/`); `docker build` проходит локально, если Docker есть; если Docker не установлен — сказать об этом в отчёте таска, а не устанавливать
- [ ] README по структуре §14: каждый ключ — где взять, по шагам, с названиями кнопок; список разрешений Meta из §6; что требует App Review/Business Verification и типичные сроки (как в §14 п.4, с оговоркой «типичные, не гарантированные»); демо → тест → боевой: что проверить («Проверить подключение»), какие команды, что увидеть; деньги и безопасность (лимиты, режимы, стоп-кран); VPS: купить сервер, поставить Docker, скопировать проект, вписать `.env`, `docker compose up -d`, логи, обновление, резервная копия `data/`; частые проблемы (по словарю ошибок §6)
- [ ] Все команды и имена переменных в README существуют в коде (сверка с `.env.example`, `start.sh`, командами бота)
- [ ] Язык — русский, без жаргона без объяснения; секретов и выдуманных значений нет
