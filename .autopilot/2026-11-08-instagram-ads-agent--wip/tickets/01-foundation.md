## Что должно заработать

Пустой, но настоящий проект: `uv sync` ставит всё, `uv run pytest -q` зелёный, `./start.sh` проверяет окружение (uv есть? `.env` есть? если нет — копирует из `.env.example` и по-русски объясняет, что заполнить) и запускает `python -m target_ai` (пока — заглушка, которая печатает в лог «приложение ещё не собрано» и выходит с кодом 0). Под этим — фундамент, на котором стоят все остальные таски: настройки, маскировка секретов в логах, тип денег, часы (реальные и симулированные), база SQLite со всеми таблицами и репозиториями.

## Из брифа, дословно

> «Суммы — в валюте рекламного аккаунта, с правильным пересчётом в минимальные единицы API: ошибка в 100 раз должна быть невозможна. Валюта и часовой пояс берутся из аккаунта.»
> «Хранение — локальная база (SQLite достаточно), расписание — внутри приложения.»
> «Запуск на моём Mac одной командой»
> «Секреты — только в .env (плюс .env.example), в логи не попадают.»

## Критерии приёмки

- [ ] `uv sync` ставит **все** зависимости из `interfaces.md` одной командой; `uv run pytest -q` зелёный
- [ ] `Settings` читает `.env` (все переменные из спеки §12, `TELEGRAM_ALLOWED_IDS` — список целых через запятую); отсутствие необязательных (`ANTHROPIC_API_KEY`, `META_*`, `TELEGRAM_BOT_TOKEN`) не роняет загрузку; `repr`/`str` настроек не показывает значения секретов
- [ ] Фильтр логов маскирует `EAA…`, `sk-ant-…`, токен бота, `access_token=…`, `appsecret_proof=…` — тест пишет каждый в лог и проверяет вывод
- [ ] `Money`: неизменяемый; `offset()` по таблице Meta (100; 1 для CLP, COP, CRC, HUF, ISK, IDR, JPY, KRW, PYG, TWD, VND); неизвестная валюта (KZT, UZS, «XXX») → исключение; `from_major(Decimal("12.34"),"USD").amount_minor == 1234`; `from_major(Decimal("1500"),"JPY").amount_minor == 1500`; дробь у JPY → исключение; сложение/сравнение разных валют → исключение; `format_ru` («1 234,50 $», «1 500 ¥», «12,00 €»); `parse_amount_ru` понимает «300 000», «1,5 тыс», «2500$», «500 usd», «1 200,50 ₽» и возвращает валюту, если она названа
- [ ] `RealClock`/`SimClock`: `now()` aware UTC; `SimClock.advance(timedelta(days=7))` сохраняется в базе и переживает пересоздание объекта
- [ ] База: миграции (нумерованные SQL) применяются при открытии, повторное открытие ничего не ломает; все таблицы из §10; WAL; `transaction()` — атомарно (тест: исключение внутри откатывает); репозитории возвращают frozen-dataclass-модели
- [ ] `approvals.consume(id, now)` — атомарный: из двух вызовов подряд успешен ровно один; просроченный — не потребляется
- [ ] `launches` — `UNIQUE(plan_id)`: вторая вставка для того же плана → понятное исключение `AlreadyLaunched`
- [ ] `start.sh` исполняемый; без `uv` печатает команду установки и выходит с кодом ≠ 0; без `.env` создаёт его из `.env.example` и объясняет, что вписать
- [ ] `.env.example` содержит все переменные с пустыми секретами и дефолтами для не-секретов (`MODEL_STRONG=claude-opus-5-5`, `MODEL_CHEAP=claude-haiku-5-5`, `META_API_VERSION=v27.0`, `DATABASE_PATH=data/target_ai.sqlite3`)
