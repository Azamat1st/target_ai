# Агентная система таргета Instagram

Telegram-бот, через который вы одни ведёте рекламу в Instagram для нескольких компаний. Вы пишете боту, какую компанию добавить. Бот изучает её Instagram, сайт и конкурентов, присылает короткий медиаплан и запускает его только после вашей кнопки «Запустить». Дальше он каждый день следит за расходом и результатами. Бот отвечает только вам.

Слова, которые встретятся дальше:

- **Токен, ключ** — длинная строка из букв и цифр, что-то вроде пароля для программы. Их нельзя никому показывать и присылать в чаты.
- **Файл `.env`** — обычный текстовый файл в папке проекта, где хранятся все ваши ключи. В нём нет ничего, кроме строк вида `ИМЯ=значение`.
- **Терминал** — окно, в которое вводят команды. На Mac: Cmd+Пробел, наберите «Терминал», Enter.
- **Рекламный аккаунт** — «кошелёк» в Meta (так называется компания Facebook и Instagram), с которого списываются деньги за рекламу.

## 1. Что это и как устроено

В системе три участника:

- **Вы** — пишете боту в Telegram, нажимаете кнопки и подтверждаете деньги.
- **Агенты на Claude** (искусственный интеллект компании Anthropic) — изучают компанию, придумывают аудитории и тексты объявлений, предлагают изменения. Сами они деньги не тратят.
- **Программа-исполнитель** — единственная, кто обращается к Meta и тратит деньги. У неё жёсткие лимиты: она не выйдет за месячный бюджет, даже если агент ошибся или предложил лишнее.

Работа идёт на трёх уровнях: **демо** (без Meta, на симуляторе, деньги не тратятся), **тест** (Meta читается по-настоящему, но ничего не создаётся) и **боевой** (настоящие кампании и настоящие деньги). Бот всегда начинает с демо.

Бот запускается на вашем Mac одной командой, а при желании работает круглосуточно на арендованном сервере (раздел 7).

## 2. Быстрый старт в демо

Для демо нужны только токен бота и ваш Telegram ID. Ключ Claude желателен, но не обязателен. Данные Meta в демо не нужны.

### Шаг 1. Установите uv

`uv` — программа, которая сама подготовит всё нужное для запуска. Откройте Терминал и введите:

```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Если у вас есть Homebrew: `brew install uv`. После установки закройте окно Терминала и откройте заново.

### Шаг 2. Получите токен бота (`TELEGRAM_BOT_TOKEN`)

1. В Telegram найдите **@BotFather** (официальный бот Telegram для создания ботов, рядом с названием стоит галочка).
2. Отправьте ему команду `/newbot`.
3. Он спросит название бота (любое, например «Мой таргетолог») и затем имя пользователя (оно должно заканчиваться на `bot`, например `moy_targetolog_bot`).
4. В ответ BotFather пришлёт токен — строку вида `цифры:буквы`. Это и есть значение `TELEGRAM_BOT_TOKEN`.

Если токен потерян или попал не в те руки, отправьте BotFather команду `/revoke` и выпустите новый.

### Шаг 3. Узнайте свой Telegram ID (`TELEGRAM_ALLOWED_IDS`)

Бот слушается только людей из этого списка, поэтому ваш числовой ID нужен обязательно.

1. В Telegram найдите **@userinfobot** и нажмите «Start» (или отправьте `/start`).
2. Он ответит сообщением со строкой `Id:` и числом. Это ваш ID.

Если людей несколько, впишите ID через запятую без пробелов: `123456789,987654321`.

### Шаг 4. Получите ключ Claude (`ANTHROPIC_API_KEY`), необязательно для демо

1. Зайдите на **console.anthropic.com** и зарегистрируйтесь или войдите.
2. Пополните баланс (раздел с оплатой, «Billing»): без денег на счёте ключ не работает.
3. Откройте раздел ключей («API Keys») и создайте новый ключ. Ключ показывается один раз, сразу скопируйте его.

Без ключа демо работает на шаблонных ответах с пометкой «демо без Claude». С ключом отвечает настоящий Claude. Для боевого уровня ключ обязателен, для тестового желателен: без него агенты работают в офлайн-демо-режиме, а «Проверить подключение» блокирующей проблемой это считает только для боевого.

### Шаг 5. Запустите

1. Скачайте или скопируйте папку проекта на Mac и в Терминале перейдите в неё: `cd путь/к/папке/target_ai`.
2. Запустите:

```
./start.sh
```

3. В первый раз скрипт создаст файл `.env` и попросит его заполнить. Откройте `.env` в любом текстовом редакторе (в TextEdit выберите «Формат → Сделать обычным текстом») и впишите значения после знака `=`, без пробелов и кавычек:

| Строка в `.env` | Что вписать | Нужна ли в демо |
|---|---|---|
| `TELEGRAM_BOT_TOKEN=` | токен от BotFather | да |
| `TELEGRAM_ALLOWED_IDS=` | ваш Telegram ID (или несколько через запятую) | да |
| `ANTHROPIC_API_KEY=` | ключ Claude | нет, но лучше с ним |
| `META_ACCESS_TOKEN=` | токен Meta (раздел 3) | нет |
| `META_APP_ID=` | номер приложения Meta (раздел 3) | нет |
| `META_APP_SECRET=` | секрет приложения Meta (раздел 3) | нет |

4. Запустите `./start.sh` ещё раз. Когда в Терминале появятся строки журнала и бот заработает, откройте его в Telegram и нажмите «Start» (или отправьте `/start`).

Остановить бота: нажмите Ctrl+C в окне Терминала.

Остальные строки `.env` менять не нужно. Для справки:

| Строка | Что значит |
|---|---|
| `MODEL_STRONG=` и `MODEL_CHEAP=` | какие модели Claude использовать для сложных и простых задач; менять не нужно |
| `META_API_VERSION=` | версия интерфейса Meta; менять, только если бот сообщит, что версия устарела |
| `DATABASE_PATH=` | где лежит база данных бота (по умолчанию папка `data/`) |
| `REPORT_TZ=` | часовой пояс для отчётов, например `Europe/Berlin`; по умолчанию UTC |
| `LOG_LEVEL=` | подробность журнала работы; по умолчанию `INFO` |

### Что делать в демо

Нажмите «➕ Компания» (или `/add`) и напишите обычным текстом, например: «добавь кофейню @coffee_x, Берлин, 1500 евро в месяц». Бот пришлёт «паспорт компании», затем медиаплан. В демо есть кнопки «⏩ +1 день» и «⏩ +7 дней» (или `/rewind 7`): они перематывают время и показывают, как бот ведёт кампанию, шлёт сводки и меняет бюджеты. Деньги не тратятся и Meta не затрагивается.

Команды бота (меню внизу экрана повторяет частые из них):

| Команда | Что делает |
|---|---|
| `/start` | приветствие и меню |
| `/help` | справка |
| `/companies` | список компаний |
| `/add` | добавить компанию |
| `/report` | отчёт |
| `/log` | журнал действий |
| `/settings` | настройки |
| `/check` | проверить подключение |
| `/stop` | стоп-кран: остановить все кампании |
| `/resume_all` | снять стоп-кран |
| `/level` | уровень работы: демо, тест или боевой |
| `/rewind` | перемотать демо на N дней, например `/rewind 7` (только демо) |

## 3. Доступы Meta

Нужны только для тестового и боевого уровней. Это самая длинная часть, но она делается один раз. Интерфейс Meta меняется, поэтому названия некоторых кнопок могут отличаться: ориентируйтесь на смысл. Названия «+Add» (добавить системного пользователя), «Assign assets» (назначить активы), «Manage app» (управление приложением) и «Upgrade» подтверждены документацией Meta на ноябрь 2026 года. Остальные названия кнопок и разделов Meta даны по смыслу: на вашем экране название может немного отличаться.

Что в итоге должно получиться: **бизнес-портфолио** (так теперь называется Business Manager) → в нём ваше **приложение** и **системный пользователь** → системному пользователю выданы **рекламный аккаунт, Страница Facebook и Instagram** → у него есть **токен** с нужными разрешениями.

### Шаг 1. Бизнес-портфолио

1. Откройте **business.facebook.com** и войдите под личным аккаунтом Facebook.
2. Если бизнес-портфолио ещё нет, создайте его (кнопка создания портфолио, название и ваши данные).
3. Откройте настройки бизнеса (Business settings): шестерёнка или пункт «Настройки бизнеса» в меню.

### Шаг 2. Рекламный аккаунт, Страница и Instagram в портфолио

В настройках бизнеса, в разделе «Аккаунты» (Accounts), должны быть:

- **Рекламные аккаунты** — нужный добавьте или создайте. Для клиентов, которые ведут свою рекламу сами, попросите расшарить их аккаунт в ваше портфолио (клиент даёт вам доступ из своих настроек бизнеса).
- **Страницы** — Страница Facebook компании.
- **Аккаунты Instagram** — Instagram компании. Он должен быть **профессиональным** (бизнес или автор): в приложении Instagram «Настройки → Тип аккаунта» переключите на профессиональный.

**Привязка Instagram к Странице.** Instagram должен быть привязан к Странице Facebook: в настройках Страницы (или в настройках бизнеса, раздел «Аккаунты Instagram») подключите аккаунт Instagram.

**Привязка Instagram к рекламному аккаунту.** В настройках бизнеса откройте рекламный аккаунт и подключите к нему аккаунт Instagram (в карточке аккаунта есть блок с Instagram или с партнёрами и активами). Без этого реклама от имени Instagram невозможна, а бот при проверке подключения покажет ошибку «у рекламного аккаунта нет доступа к Instagram-аккаунту».

### Шаг 3. Приложение

1. Откройте **developers.facebook.com** и войдите тем же аккаунтом. Если просит, зарегистрируйтесь как разработчик.
2. Создайте приложение (в разделе «Мои приложения» кнопка создания). Тип приложения выберите «Бизнес» (или близкий по смыслу: приложение для работы с рекламой и бизнес-инструментами). Привяжите приложение к вашему бизнес-портфолио.
3. В панели приложения добавьте продукт **Marketing API** (раздел «Добавить продукт» или «Products»). С этого момента у приложения появляется уровень доступа Limited (см. раздел 4).
4. В настройках приложения, в разделе основных настроек («Settings → Basic»), найдите:
   - **Идентификатор приложения** (App ID) — это `META_APP_ID`;
   - **Секрет приложения** (App Secret) — нажмите «Показать» и введите пароль Facebook; это `META_APP_SECRET`.

Эти два значения нужны, чтобы бот мог проверять токен и сроки его действия. Они не обязательны, но с ними проверка подключения точнее.

### Шаг 4. Системный пользователь

Системный пользователь — «робот-сотрудник» бизнес-портфолио, от имени которого работает бот. Его токен не привязан к вашему личному входу в Facebook.

1. В настройках бизнеса откройте **Пользователи → Системные пользователи** (System Users) и нажмите «Добавить» («+Add»).
2. Дайте имя (например, «Таргет-бот») и роль **Админ** (на Limited-доступе лучше сразу выбирать администратора системы).
3. Выдайте ему активы: выберите пользователя и нажмите «Назначить активы» («Assign assets»):
   - **Приложение** — ваше приложение, с полным контролем (право «Управление приложением», «Manage app»);
   - **Рекламный аккаунт** — с полным контролем (управление кампаниями);
   - **Страница** — с задачей «Реклама» (Advertise) и доступом к контенту;
   - **Аккаунт Instagram** — доступ к управлению.

### Шаг 5. Токен Meta (`META_ACCESS_TOKEN`)

1. Выберите системного пользователя и нажмите кнопку создания токена («Generate token» / «Сгенерировать токен»).
2. Выберите ваше приложение.
3. Срок действия: «Никогда» (токен без срока) либо 60 дней. Рекомендуется токен без срока, если Meta даёт такой выбор. Токен с 60-дневным сроком придётся менять по расписанию; бот предупредит заранее.
4. Отметьте разрешения:

| Разрешение | Зачем |
|---|---|
| `ads_management` | создавать и менять рекламу |
| `ads_read` | читать рекламные аккаунты и статистику |
| `pages_show_list` | видеть список Страниц |
| `pages_read_engagement` | читать данные Страницы |
| `pages_manage_ads` | показывать рекламу от имени Страницы, в том числе с переходом в Direct |
| `pages_read_user_content` | читать публикации и комментарии на Странице |
| `instagram_basic` | читать профиль и публикации Instagram |
| `instagram_manage_insights` | читать статистику Instagram и данные конкурентов |
| `business_management` | желательно: чтение активов бизнес-портфолио |

5. Нажмите создание токена и сразу скопируйте его: Meta показывает токен один раз. Вставьте в `.env` как `META_ACCESS_TOKEN=`.

Если какого-то разрешения нет в списке, значит, оно не выдано приложению или не добавлен продукт Marketing API (шаг 3). Бот при проверке подключения прямо напишет, какого разрешения не хватает.

Для рекламы в Direct (сообщения в Instagram) и форм заявок боту нужен токен Страницы. Отдельно выпускать его не надо: бот получает его сам от токена системного пользователя, если у пользователя на Странице есть задача «Реклама». Поэтому важно выдать её на шаге 4.

### Шаг 6. Проверьте

Перезапустите бота, откройте Telegram, нажмите «🔌 Проверить подключение» (или отправьте `/check`). Бот проверит токен, разрешения, рекламные аккаунты, Страницы и связь Instagram с рекламным аккаунтом и напишет по пунктам, что в порядке (✅), что стоит проверить (⚠️) и что мешает работе (❌). Подробнее — раздел 5.

## 4. Что требует проверки и сколько это занимает

Главное: **для вашей схемы проверки не нужны.** Приложением пользуетесь только вы, а все рекламные аккаунты (свои и клиентские) расшарены в ваше бизнес-портфолио. Подробности:

- **Проверка приложения (App Review) не нужна.** Для своих аккаунтов хватает Standard-доступа к разрешениям `ads_read` и `ads_management`, он выдаётся сразу.
- **Проверка бизнеса (Business Verification) не нужна.**
- **Токен системного пользователя** выпускается сразу. Он бессрочный или на 60 дней, на ваш выбор.
- **Уровень доступа к Marketing API.** Сначала у вас Limited: он даётся сразу, но у него медленные лимиты запросов, поэтому запуск кампании занимает несколько минут (бот так и пишет). Full включается автоматически, когда набирается не менее 500 запросов за 15 дней с долей ошибок меньше 15%: тогда в App Review появляется кнопка «Upgrade». Для работы он не обязателен.
- **Когда проверки всё же понадобятся.** Если вы захотите работать с чужими аккаунтами, которые не расшарены вам, нужен Advanced-доступ к разрешениям: App Review по каждому разрешению и Business Verification. App Review обычно занимает 3–7 рабочих дней, Business Verification — несколько рабочих дней.

Сроки типичные, не гарантированные: официального обещания у Meta нет, и они могут быть как короче, так и заметно длиннее.

## 5. Демо, тест, боевой

Переключение: команда `/level` (или кнопки в «⚙️ Настройки»). Можно написать и словами: `/level тест`, `/level боевой`, `/level демо`.

### Демо

Уровень по умолчанию. Meta не используется, деньги не тратятся. Нужны только токен бота и ваш ID. Пройдите полный цикл: добавьте компанию, получите паспорт и медиаплан, нажмите «Запустить», перемотайте время, посмотрите `/report`.

### Демо → тест

Что нужно: заполненные `META_ACCESS_TOKEN` (и желательно `META_APP_ID`, `META_APP_SECRET`) и `ANTHROPIC_API_KEY` в `.env`, бот перезапущен.

1. Отправьте `/check` или нажмите «🔌 Проверить подключение». В ответе будет список с отметками ✅, ⚠️ и ❌.
2. Исправьте все ❌ (подсказка, что делать, написана под каждой строкой).
3. Отправьте `/level тест`.

В тестовом уровне бот по-настоящему читает данные Meta (аккаунты, Instagram, статистику). Создание кампаний проверяется пробными запросами Meta: они проверяют, примет ли Meta такую кампанию, но ничего не создают и ничего не включают. Если Meta отклонила пробный запрос, бот покажет причину на русском.

### Тест → боевой

Боевой уровень включается только когда выполнены оба условия: «Проверить подключение» не показывает блокирующих проблем (❌), и вы нажали кнопку подтверждения.

1. Отправьте `/check` и убедитесь, что ❌ нет. Предупреждения ⚠️ прочитайте внимательно.
2. Отправьте `/level боевой`. Бот ещё раз проверит подключение и покажет, что изменится.
3. Нажмите «✅ Включить боевой».

С этого момента кампании создаются по-настоящему и тратят настоящие деньги, но только с вашими кнопками (в режиме «С подтверждением») и в пределах месячного лимита. Перед первым боевым запуском задайте месячный лимит каждой компании (карточка компании → «💰 Изменить лимит») и начните с небольшой суммы.

### Выход из боевого

`/level демо` или `/level тест` попросит подтверждение и **поставит боевые кампании на паузу**: без управления они продолжали бы тратить деньги. Возобновлять их потом нужно по одной, в карточке компании кнопкой «▶️ Возобновить».

## 6. Деньги и безопасность

**Бот не может потратить больше, чем вы разрешили.** Это обеспечивает программа-исполнитель, а не искусственный интеллект: что бы ни предложил агент, лимиты проверяет обычный код.

- **Месячный лимит компании.** Задаётся в карточке компании («💰 Изменить лимит»). Это потолок расходов компании на календарный месяц. Дополнительно лимит передаётся самой Meta как предел расхода кампании: даже если бот остановится или сломается, Meta не позволит потратить больше остатка.
- **Дневной потолок.** Бот делит остаток месяца на оставшиеся дни, с запасом на то, что Meta иногда тратит в отдельный день больше дневного бюджета. Дневные бюджеты кампаний вместе не превышают этот потолок. Если денег осталось слишком мало для всех групп объявлений, слабые группы отключаются, а если не хватает даже на одну, компания ставится на паузу до конца месяца.
- **Лимит исчерпан.** Остаток равен нулю — все кампании компании на паузе, вам приходит уведомление.
- **Одна активная кампания на компанию.** Новый запуск ставит предыдущую кампанию на паузу.
- **Суммы всегда в валюте рекламного аккаунта.** Бот показывает сумму со знаком валюты и просит нажать «Всё верно». Курсы он не пересчитывает: если вы напишете сумму в другой валюте, он попросит ввести сумму в валюте аккаунта. **Meta не поддерживает тенге (KZT) и узбекские сумы (UZS):** рекламный аккаунт в этих валютах бот подключить не сможет и скажет об этом. Для таких компаний заведите рекламный аккаунт в поддерживаемой валюте (например, доллары или евро).

### Режимы компании

Режим выбирается в карточке компании кнопкой «Режим → …».

- **С подтверждением** (по умолчанию). Всё, что увеличивает расход (запуск, возобновление, увеличение бюджета), бот делает только после вашей кнопки. Снижение расхода и паузы бот делает сам.
- **Автономный.** Бот сам вносит изменения и увеличивает расход, но не выше дневного потолка и месячного лимита. Включение режима требует подтверждения. Начинайте с «С подтверждением» и переходите на автономный, когда привыкнете к работе бота.

### Стоп-кран

Кнопка «🛑 Стоп-кран» или команда `/stop` сразу ставит на паузу все кампании системы по всем компаниям и запрещает включать и увеличивать расход, пока вы не снимете его. Если на какой-то кампании Meta вернула ошибку, остальные всё равно остановятся, а не остановленные бот перечислит в ответе.

Снять стоп-кран: `/resume_all`, затем подтверждение. Сам по себе он ничего не включает: каждую компанию вы возобновляете отдельно в её карточке.

### Безопасность

- Бот отвечает только людям из `TELEGRAM_ALLOWED_IDS`. Остальным он отвечает отказом: «Доступ закрыт.»
- Файл `.env` содержит все ключи: не отправляйте его в чаты и почту, не выкладывайте в интернет. В проекте он исключён из хранилища и из Docker-образа.
- Ключи и токены не попадают в журнал и сообщения бота.
- Если ключ мог утечь: выпустите новый (BotFather → `/revoke`; в console.anthropic.com отзовите ключ; в Meta создайте новый токен системного пользователя), вставьте в `.env` и перезапустите бота.
- Если вы потеряли ноутбук или потеряли доступ к серверу, отзовите токен Meta в настройках бизнеса.

## 7. Развёртывание на сервере (VPS)

VPS — арендованный компьютер в интернете, который работает круглосуточно. Так бот не зависит от вашего Mac: не уснёт, когда вы закроете крышку. Ничего не развёртывается автоматически: вы сами выполняете шаги ниже.

Что нужно: VPS с Linux (например, Ubuntu 24.04), хватит одного ядра и 1–2 ГБ памяти; бот сам обращается к Telegram, Claude и Meta, поэтому открывать порты и покупать домен не нужно.

### Шаг 1. Купите сервер

Выберите любого хостинг-провайдера с VPS. При заказе выберите операционную систему Ubuntu (LTS). Провайдер пришлёт адрес сервера и способ входа (пароль или SSH-ключ). Желательно выбрать страну, откуда доступны Telegram, Meta и Anthropic.

### Шаг 2. Подключитесь к серверу

В Терминале на Mac: `ssh root@АДРЕС_СЕРВЕРА` (или имя пользователя, которое прислал провайдер). Введите пароль.

Совет: если вы вошли как `root`, создайте обычного пользователя (`adduser bot`, `usermod -aG sudo bot`) и дальше работайте под ним. Образ бота рассчитан на пользователя с номером 1000: это первый обычный пользователь на сервере.

### Шаг 3. Установите Docker

Docker — программа, которая запускает бота в изолированной «коробке», одинаково на любом сервере. Установка одной командой (официальный скрипт Docker):

```
curl -fsSL https://get.docker.com | sh
```

Затем добавьте себя в группу docker, чтобы не вводить `sudo` каждый раз, и войдите заново: `sudo usermod -aG docker $USER`. Проверка: `docker compose version` должна показать версию.

### Шаг 4. Скопируйте проект на сервер

На вашем Mac (не на сервере), из папки, где лежит папка проекта:

```
rsync -av --exclude .venv --exclude data --exclude .autopilot --exclude .git target_ai/ ПОЛЬЗОВАТЕЛЬ@АДРЕС_СЕРВЕРА:target_ai/
```

Файл `.env` с Mac копировать можно: он не входит в исключения выше и поедет вместе с проектом. Если хотите хранить на сервере другие ключи, создайте `.env` там сами (шаг 5).

### Шаг 5. Впишите `.env`

На сервере:

```
cd target_ai
cp -n .env.example .env
nano .env
```

Впишите значения так же, как в разделе 2 (и Meta из раздела 3, если нужен тестовый или боевой уровень). Сохранить в `nano`: Ctrl+O, Enter, затем выйти: Ctrl+X.

Создайте папку для базы данных — в ней бот хранит компании, историю и настройки:

```
mkdir -p data
sudo chown -R 1000:1000 data
```

Вторая команда обязательна: бот в контейнере работает под пользователем с номером 1000 и должен иметь право писать в `data/`. Без неё бот не сможет создать базу и будет бесконечно перезапускаться. Это нужно и тогда, когда вы работаете под `root`, и когда номер 1000 занят другим пользователем сервера (например, `ubuntu`): права выдаются по номеру, а не по имени.

Не запускайте бота на Mac и на сервере одновременно с одним и тем же токеном бота: Telegram не позволяет двум программам читать одного бота.

### Шаг 6. Запустите

```
docker compose up -d
```

Первый раз сборка займёт несколько минут. `-d` означает «в фоне»: бот работает, пока вы закрыли Терминал. Если сервер перезагрузится, бот поднимется сам.

### Журнал и состояние

- Журнал в реальном времени: `docker compose logs -f` (выход: Ctrl+C, бот при этом продолжит работу).
- Последние 100 строк: `docker compose logs --tail 100`.
- Состояние: `docker compose ps`.
- Перезапуск: `docker compose restart`.
- Остановка: `docker compose down` (данные в `data/` сохранятся).

### Обновление

Скопируйте новую версию проекта на сервер той же командой `rsync` (шаг 4), затем на сервере:

```
cd target_ai
docker compose up -d --build
```

Данные в `data/` и `.env` при этом не теряются.

### Резервная копия

Всё, что бот накопил (компании, история, настройки), лежит в папке `data/`. Это единственное, что нельзя восстановить. Для копии остановите бота, заберите папку и запустите заново:

```
docker compose stop
tar czf backup-$(date +%F).tar.gz data
docker compose start
```

Скачать архив на Mac: `scp ПОЛЬЗОВАТЕЛЬ@АДРЕС_СЕРВЕРА:target_ai/backup-*.tar.gz .` Делайте копию регулярно и перед обновлением. Файл `.env` тоже сохраните, но только в надёжном месте: в нём все ключи.

## 8. Частые проблемы

Бот на русском описывает проблему и подсказывает, что делать. Ниже самые частые случаи.

**Бот не запускается и пишет «Не задан токен бота» или «Не задан список разрешённых Telegram ID».** Откройте `.env` и впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ALLOWED_IDS` (раздел 2). Значения пишутся без пробелов и кавычек.

**Бот в Telegram молчит.** Проверьте, что ваш ID есть в `TELEGRAM_ALLOWED_IDS`, а бот запущен (на Mac окно Терминала открыто, на сервере `docker compose ps`). Не запущен ли тот же бот ещё где-то (на Mac и на сервере одновременно)?

**«Токен Meta истёк».** Выпустите новый токен системного пользователя (раздел 3, шаг 5), вставьте в `META_ACCESS_TOKEN` и перезапустите бота.

**«Токен Meta отозван или недействителен».** То же: выпустите новый токен. Токен слетает, если сменили пароль Facebook, удалили приложение или системного пользователя, или отозвали его вручную.

**«Не хватает разрешения …».** Выпустите токен заново и отметьте названное разрешение (список в разделе 3, шаг 5). Проверьте, что продукт Marketing API добавлен в приложение и что системному пользователю выданы Страница и рекламный аккаунт.

**«У рекламного аккаунта нет доступа к Instagram-аккаунту».** Подключите Instagram к рекламному аккаунту в настройках бизнеса (раздел 3, шаг 2) и убедитесь, что Instagram привязан к Странице.

**Не приняты условия пользовательских аудиторий.** Откройте в Ads Manager (рекламный кабинет Meta) создание аудитории и примите условия использования. Один раз для каждого рекламного аккаунта.

**«Лимит расходов кампании меньше минимума Meta» или «Дневной бюджет меньше минимума Meta».** Сумма слишком мала. Увеличьте месячный лимит компании или уменьшите число групп объявлений.

**Объявление отклонено.** Отклонённое объявление включить нельзя, Meta это запрещает. Бот создаёт исправленное объявление заново в той же группе и убирает старое. Причину отклонения он напишет в сообщении.

**Нужны получатель и плательщик рекламы (для стран ЕС).** Правила Евросоюза требуют указать, кто получает рекламу и кто за неё платит. Бот спросит это у вас: ответьте названиями.

**«Версия API устарела».** В `.env` укажите актуальную версию в `META_API_VERSION` (смотрите на developers.facebook.com, раздел обновлений Graph API) и перезапустите бота.

**«Неверный параметр …».** Meta отклонила один из параметров. Подробности в журнале действий (`/log`) и в журнале работы бота (раздел 7, «Журнал»).

**«Лимит запросов, повторяю через N минут».** Meta ограничивает частоту обращений, особенно на уровне Limited. Ничего делать не нужно: бот сам подождёт и повторит.

**«Временная ошибка Meta, повторяю».** Сбой на стороне Meta. Бот повторит запрос сам.

**Рекламный аккаунт в тенге или сумах.** Meta не поддерживает эти валюты (раздел 6). Нужен аккаунт в другой валюте.

**Рекламный аккаунт ограничен, на проверке рисков, проблема с оплатой.** Откройте Ads Manager и посмотрите уведомления у аккаунта: Meta пишет причину и что исправить. Пока аккаунт не активен, бот не запускает кампании, а «Проверить подключение» показывает причину.

**Остальные ошибки Meta.** Бот пишет «Meta вернула ошибку: …» с кодом. Каждая ошибка записана в журнал, ничего не теряется молча.

**Бот постоянно перезапускается, в журнале ошибка доступа к базе (permission denied, unable to open database).** У бота нет права писать в папку `data/`. Выполните на сервере `sudo chown -R 1000:1000 data`, затем `docker compose restart`.

**Я случайно удалил `data/`.** Бот начнёт с чистого листа. Поэтому делайте резервные копии (раздел 7).
